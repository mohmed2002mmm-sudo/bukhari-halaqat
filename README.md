# حلقات البخاري (`bukhari-halaqat`)

مشروع ويب لإدارة ومتابعة شؤون مجمع خيري وحلقات التحفيظ، يضم واجهات مخصصة للأدوار والصلاحيات المختلفة مع طبقة تخزين بيانات عبر `storage.js`.

## فكرة المشروع وأهدافه
- تنظيم العمل اليومي والإداري داخل الحلقات والمجمع الخيري.
- توفير واجهات واضحة ومستقلة لكل دور داخل النظام لتسهيل المتابعة والوصول السريع.
- حفظ البيانات وإدارتها برمجياً عبر ملف `storage.js`.

## هيكل الملفات والصفحات
- **`index.html`**: نقطة البداية والصفحة الرئيسية للمشروع.
- **`system.html`**: صفحة النظام العامة وإدارة العمليات الأساسية للمشروع.
- **`admin.html`**: لوحة/واجهة الإدارة للإشراف العام وإعدادات النظام.
- **`supervisor.html`**: واجهة المشرف لمتابعة الحلقات والمعلمين وسير العمل.
- **`teacher.html`**: واجهة المعلم لمتابعة الطلاب والحلقات الخاصة به.
- **`attendance.html`**: صفحة تسجيل ومتابعة الحضور والغياب.
- **`storage.js`**: ملف الجافاسكربت المسؤول عن إدارة البيانات والتخزين في المشروع.

## طريقة التشغيل والاستخدام
1. افتح ملف `index.html` مباشرة في المتصفح، أو شغّل المشروع عبر خادم محلي (مثل Live Server في VS Code) لضمان عمل كافة الخصائص بسلاسة.
2. انتقل بين الصفحات (`admin.html`، `supervisor.html`، `teacher.html`، `attendance.html`، `system.html`) بحسب الدور أو الوظيفة المطلوبة.

## ملاحظات مهمة
- إذا كان المشروع يعتمد على التخزين المحلي في المتصفح (`localStorage` عبر `storage.js`)، فستكون البيانات مرتبطة بالمتصفح والجهاز المستخدم ما لم يتم ربطها بقاعدة بيانات خارجية لاحقاً.
- يُنصح بعدم رفع ملفات أو بيانات حساسة أو مفاتيح وصول خاصة داخل مستودع عام (`Public`).
